## 4. scripts/demo-video.sh review [reviewed — issues reported, script unchanged]

1. **MED — secret exposure**: `env $(grep -v '^#' .env | xargs) MERCHANT_PRICE=0.10 npx tsx server.ts`
   puts `FACILITATOR_PRIVATE_KEY` in the process argv, visible in `ps` while the
   merchant starts. Also breaks on any `.env` value with spaces/quotes.
2. **LOW — unquoted kill**: `kill $(lsof -ti :$MERCHANT_PORT)` word-splits; harmless
   with 0–1 PID, errors with more.
3. **LOW — brittle price check**: `sed` parses `/health` JSON; any field reorder or
   spacing change silently misreads the price.
4. **LOW — AppleScript injection**: `$PROMPT` is interpolated into a double-quoted
   `osascript` string; a `"` or `\` in the prompt breaks the Terminal open step.
   Current prompt is safe.
5. **LOW — indiscriminate port kills**: whatever holds :7610/:4021 is killed,
   merchant/UI or not.
6. **Info — relay auth incompatibility**: the script starts the relay `--no-auth`,
   which is correct for `dabao-client.ts` — the TS client never sends an `AUTH`
   line, so a token-enabled relay would refuse it after the 3 s auth timeout.
   Only `tools/eth_client.py --tcp` speaks AUTH. Don't enable relay auth tomorrow.
