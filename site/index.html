Try the live deployment

The paid endpoint is deployed and answering at 0gaze.tech/generate. The 402 carries a real x402 payment requirement: 0.01 USDT via EIP-3009 on Whitechain Sepolia. A payment signed by any EIP-3009-capable key settles onchain through the facilitator and returns the paid artifact.

Six kinds of private

See privately

Approvals and balances render only in your glasses. On the bench the glasses are an independent display: the Mac beside them never shows the card.

Think privately

0G Private Computer thinking, with a request ID on every decision.

Remember privately

Episode records belong to you, with a local journal as a safe stop.

Prove human privately

A guided head-motion challenge proves the enrolled wearer is present; the motion signature is calibrated per wearer and never leaves the machine. An identity check guards larger spends.

Pay privately

The chip’s key is born inside it and never leaves; payments go out as EIP-3009 authorizations the facilitator settles onchain.

Fail safely

If proof, identity, storage, or hardware is unavailable, the agent stops or degrades locally.

Run the proof yourself

The demo makes a real motion proof on your machine, checks the challenge, asks the chip to approve it, and independently recovers who approved.

git clone https://github.com/ivcained/0gaze.git
cd 0gaze/zkp/prover
npm install
node scripts/setup-dev.mjs
node scripts/e2e-test.mjs
# With the Dabao relay running on port 7601:
npx tsx scripts/demo-chip.mjs 7601
