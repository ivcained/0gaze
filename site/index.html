Try the live deployment

The paid inference endpoint is deployed and answering at 0gaze.tech/generate. Anyone can request a quote:

curl -i https://0gaze.tech/generate

The 402 response carries a real x402 payment requirement: 0.01 USDT via EIP-3009 on Whitechain Sepolia. A payment signed by any EIP-3009-capable key settles onchain through the facilitator and returns the paid artifact.

Run the proof yourself

The real-chip ZKP demo generates a Groth16 motion proof, verifies its challenge, asks the Dabao to sign the motion witness, and independently recovers the signer.

git clone https://github.com/ivcained/0gaze.git
cd 0gaze/zkp/prover
npm install
node scripts/setup-dev.mjs
node scripts/e2e-test.mjs
# With the Dabao relay running on port 7601:
npx tsx scripts/demo-chip.mjs 7601
Read-only public proof page. No wallet connection. Testnet funds only. Read the design
